# Lokale Schriftdateien

- Montserrat und Source Sans 3 stammen aus der Google Fonts CSS API.
- Die Dateien werden lokal ausgeliefert, damit beim Seitenaufruf keine Schriftanfrage an Google erforderlich ist.
- Beide Schriftfamilien werden unter der SIL Open Font License 1.1 bereitgestellt.
- Quellen: https://fonts.google.com/specimen/Montserrat und https://fonts.google.com/specimen/Source+Sans+3
